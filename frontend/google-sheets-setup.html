Suas empresas, prontas no Google Sheets.

A exportação cria uma planilha no seu Drive com filtros, cabeçalho fixo, linhas alternadas e listas para acompanhar o contato de cada empresa.

O Google exige que o site tenha um cliente OAuth próprio. A conexão da sua conta com o ChatGPT não autoriza automaticamente este site. Essa configuração é feita uma vez.

  1. Acesse o Google Cloud. Crie um projeto chamado MAOF Scraper, ou selecione um projeto existente.
  2. No mesmo projeto, abra a Google Sheets API e clique em Ativar.
  3. No Google Auth Platform, configure o nome MAOF Scraper, o e-mail de suporte e o e-mail de contato. Para uma conta pessoal, selecione público Externo. Enquanto estiver em teste, adicione seu próprio e-mail em Público → Usuários de teste.
  4. Em Acesso a dados, selecione o escopo https://www.googleapis.com/auth/drive.file. Ele permite criar e trabalhar com os arquivos deste aplicativo, sem acesso geral ao seu Drive.
  5. Abra Clientes → Criar cliente. Escolha Aplicativo da Web. Em Origens JavaScript autorizadas, inclua https://maof-maps-scraper.vercel.app. Para usar outro endereço do mesmo site, adicione também a origem exata desse endereço. Não há URI de redirecionamento a configurar neste fluxo de autorização por popup.
  6. Copie apenas o ID do cliente, terminado em .apps.googleusercontent.com. Não copie o client secret.
  7. Volte ao scraper, clique em Configurar Google, cole o ID e salve. O ID público fica salvo nesse navegador.
  8. Abra os resultados de uma busca e clique em Abrir no Google Sheets. Escolha sua conta Google e autorize a criação dos arquivos. A planilha será criada e aberta na mesma aba.

Acompanhamento de contatos

As opções são: Não contatado, Aguardando resposta, Respondeu, Não respondeu, Retornar depois, Sem interesse e Cliente fechado. Há também colunas para data do contato, responsável, próximo retorno e observações.

Cada exportação cria uma nova planilha com as empresas e os filtros visíveis naquele momento. As planilhas anteriores e os status que você preencheu são preservados. Para continuar o acompanhamento, reabra a planilha já criada no seu Drive.

Se o Google mostrar um erro

  • origin_mismatch: confira se a origem autorizada é exatamente o endereço que aparece no scraper, com https:// e sem caminho no final.
  • access_denied: confira se sua conta está na lista de usuários de teste do projeto.
  • API has not been used / disabled: ative a Google Sheets API no mesmo projeto do cliente OAuth.
  • Janela bloqueada: permita popups e scripts de accounts.google.com para o site.

Não são necessárias chaves de API, client secrets ou senhas no código do scraper. O token de acesso fica apenas na memória da aba e não é salvo no servidor.
